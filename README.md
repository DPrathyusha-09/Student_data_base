Student Record Management System in C

Project Overview

The Student Record Management System is a menu-driven application developed using the C programming language. It is designed to manage student records efficiently using a Singly Linked List (SLL) data structure.

The system allows users to add, delete, display, modify, sort, reverse, and save student records. It uses dynamic memory allocation to create and manage student records at runtime.

Each student record contains:

Roll Number

Student Name

Marks

Objectives

To understand and implement the Singly Linked List data structure.

To perform insertion, deletion, searching, and traversal operations.

To understand dynamic memory allocation using malloc() and free().

To organize a C project using multiple source files and header files.

To perform file handling operations for storing student records permanently.

Technologies Used

Programming Language: C

Data Structure: Singly Linked List

Concepts: Pointers, Structures, Dynamic Memory Allocation, File Handling

Development Environment: Ubuntu Linux

Compiler: GCC

Version Control: Git and GitHub

Features
The application provides the following operations:
Add Student Record: Adds a new student record with a unique roll number, name, and marks.

Delete Student Record: Deletes a student record based on the selected search criteria.

Display Student Records: Displays all student records in a tabular format.

Modify Student Record: Updates the details of an existing student.

Save Student Records: Stores student records in a file named student.dat.

Sort Student Records: Sorts student records based on the selected criteria.

Delete All Records: Deletes all student records and releases allocated memory.

Reverse Student Records: Reverses the order of the linked list.

Exit: Allows the user to save records and exit or exit without saving.



Concepts Learned

Implementation of Singly Linked Lists.

Structures and self-referential structures.

Pointers and pointer-to-pointer concepts.

Dynamic memory allocation using malloc() and free().

Linked list traversal and manipulation.

File handling using fopen(), fwrite(), and fclose().

Modular programming using multiple C source files.

Compilation and build automation using Makefile.

Version control using Git and GitHub.


Conclusion

The Student Record Management System demonstrates the practical implementation of a Singly Linked List using the C programming language. It provides an efficient way to manage student records through different operations and helps develop a strong understanding of pointers, dynamic memory allocation, data structures, and file handling.
